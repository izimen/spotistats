## 2. Research: Spotify Web API w 2026 (tryb Development)

Zrodla: [Migration guide luty 2026](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide), changelogi [luty](https://developer.spotify.com/documentation/web-api/references/changes/february-2026), [marzec](https://developer.spotify.com/documentation/web-api/references/changes/march-2026), [maj](https://developer.spotify.com/documentation/web-api/references/changes/may-2026), [lipiec](https://developer.spotify.com/documentation/web-api/references/changes/july-2026).

| Co | Stan | Wplyw na SpotiStats |
|----|------|---------------------|
| `GET /me/top/{type}`, `GET /me/player/recently-played` | Dzialaja, bez zmian limitow | Rdzen aplikacji OK |
| `popularity` (artysta, utwor, album), `followers` (artysta) | **Usuniete** | Pole "streams" na dashboardzie = 0 (nie jest wyswietlane), scoring "ukrytych perelek" w Discovery nie dziala (wszystko = 0) |
| `genres`, `images` artysty, `release_date` albumu, `preview_url` | Nie wymienione jako usuniete | Top gatunek i "wiek sluchania" dzialaja; `preview_url` i tak zwykle `null` od 2024 (fallback do linku Spotify jest) |
| `GET /me`: `email`, `country`, `product` | **Usuniete** | Obsluzone (nullable `User.email`, profil ukrywa pola) |
| `GET /search` | `limit` max **10** (bylo 50) | Discovery juz uzywa 10 |
| `audio-features`, `recommendations` (od XI 2024) | Niedostepne | Music DNA zwraca null → frontend pokazuje lokalne heurystyki |
| Batch `GET /tracks`, `/artists`, `/albums` | **Usuniete** | Nieuzywane — nie wolno ich wprowadzac |
| Limity | Wlasciciel musi miec Premium, max 5 uzytkownikow, od VII 2026 quota liczona **per konto dewelopera** (nie per Client ID), 429 z `"reason": "QUOTA_EXCEEDED"` | Patrz OPERATIONS.md |
| Redirect URI | `localhost` niedozwolony — tylko HTTPS albo `http://127.0.0.1` | README poprawione |

| # | Funkcja | Opis | Effort |
